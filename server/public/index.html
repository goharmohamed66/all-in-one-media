📖 إزاي أشغّل البرنامج؟ (شرح للمبتدئين)

🪟 على ويندوز

1. فوق في «التحميل والتحديثات» اضغط زر «نسخة ويندوز» (أو نزّله من صفحة Releases على GitHub).

2. افتح الملف اللي نزل: All-In-One-Media-Setup.exe (دبل-كليك).

3. لو ظهرت رسالة زرقاء من ويندوز (SmartScreen): اضغط More info ثم Run anyway — البرنامج سليم بس مش موقّع بشهادة مدفوعة.

4. كمّل التثبيت (Next) → هيفتح، وهتلاقيه في قائمة Start باسم «All In One Media».

مش محتاج تنزّل أي حاجة تانية — yt-dlp و ffmpeg جوه البرنامج.

🍎 على ماك

1. اضغط زر «نسخة ماك» فوق (أو نزّل ملف .dmg من Releases على GitHub).

2. افتح ملف All-In-One-Media-macOS.dmg، واسحب أيقونة البرنامج لمجلد Applications.

3. أول مرة بس: روح Applications، كليك يمين على البرنامج → Open → Open. (عشان البرنامج مش موقّع بشهادة أبل المدفوعة).

4. لو ظهرت رسالة إنه «تالف» أو ميتفتحش، افتح Terminal واكتب:

xattr -cr "/Applications/All In One Media.app"

وبعدها افتحه عادي.

👨‍💻 للمطوّر (تشغيل من الكود)

git clone https://github.com/goharmohamed66/all-in-one-media.git
cd all-in-one-media
npm install
